# WeChatQRCode Models

The QR pipeline expects the following OpenCV WeChatQRCode model files in this directory:

- `detect.prototxt`
- `detect.caffemodel`
- `sr.prototxt`
- `sr.caffemodel`

Download them with:

```bash
./scripts/setup_wechat_qrcode_models.sh
```

The binary/model files themselves are ignored by Git.
